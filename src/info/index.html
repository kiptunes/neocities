About the Site

This site is mainly my place to separate personal things from my other devwork. It uses the Bulma CSS framework (specifically the alt version without helpers) for theming, responsiveness, and other components like the breadcrumbs at the bottom of this page.

// FAQ

Why make a website?

 Among other reasons: for fun, to keep the old web alive, to make a corner of the internet entirely yours.

Why not use javascript?

 The point of this site at the time of conception was to re-familiarize myself with css, so I wanted to do some silly stuff with css only. In the future, this site will probably use more js! Just not right now.

 (Although, others might prefer not to use javascript because it can bloat a website. At the end of the day, it depends on your usecase and who you want your site to be seen by.)

Why use a framework?

 I wanted to make this site responsive (able to adapt to different screen sizes), and it's just a little bit faster to use a framework to accomplish that. tl;dr I'm just lazy

Why does your CSS look like that?

 I really wish I remembered

Can I copy or modify this site's code?

 Yes! My code is free use without attribution, but if you also keep the part of the code that uses Bulma CSS, keep in mind that it uses the MIT license, which has different requirements.

Applications

Name Purpose Notes
Krita 2d art

The drawing program I use on laptop. I don't bother with many complicated tools, so I've personally never felt the need to migrate to CSP or Sai.

Aseprite Pixel art

You don't have to pay the $20 for Aseprite! It's open source. You can build it from their github repo.

Inkscape Vector art

I use Inkscape to sketch out webpage ideas and sometimes create vector graphics. Comparable to Adobe Illustrator without the pricetag. Also consider Photopea if you're looking for a Photoshop alternative.

Blender 3d art

Application for (but not limited to) 3d modeling, rendering, animation, and editing.

FreeCAD CAD

The application I use for more precise measurements and for 3D print cases, stands, etc.

Opentoonz Animation

I rarely animate, but when I do, I use Opentoonz. If you run Linux, you can find the package on the github page, since it's not on the main site.

Godot Engine Gamedev

Lightweight engine that requires no network sign-on. Uses GDScript (an engine-native language similar to python) or C#, whichever you prefer.

KiCAD PCB design

Multipurpose schematic editor. Extensive libraries, and there's an extension for FreeCAD that allows PCB model imports from KiCAD.

Code OSS IDE

VSCode without Microsoft specific functionality -- i.e., telemetry-free.

Notes

 The x280 serves well for a dev laptop. Cheap, sturdy, and light, my only complaint is that the color profile bothers me when I draw no matter how much I tinker with it.

 Overall, a reliable computer if you don't mind the small screen. Beware that it has soldered RAM.

Pen tablet

Specs
Area 10x6.25"
Thickness 10mm
Pressure sensitivity 8,192 levels
Programmable keys 12 on tablet, 2 on stylus

Notes

 I use this tablet with OpenTabletDriver on Linux, and it works without any major hiccups. I hear Huion tablets are usually well supported by Linux drivers, even if they are not propietary.

 The only shame is that the pen-activated shortcut buttons along the top of the tablet are unsupported by the otdriver mapping interface. I'd like to try coding an extension that adds the functionality of turning some portion of the tablet area into shortcuts, when I get the chance...
