Webrings

About

  Webrings are a network of websites grouped by common interest, whose subject can be any number of things, including fandom, skill level, or shared tools.

  The earlier definition of a true 'webring' had stricter restrictions about the content of a website, but on Neocities nowadays it's more common that the only requirement of a webring is that the overarching theme of the webring is simply featured somewhere on your site.

  The members of a webring are linked together so that you can navigate forwards and backwards to the neighbors of the site, and the last site links to the first in a 'ring'.

Why is hotlinking bad?

As defined by Neocities, hotlinking is when a non-HTML file hosted by Neocities is embedded into another site that is not hosted by Neocities, using up the host server's bandwidth. Hotlinked files are also susceptible to breaking when the host website is rearranged. It is disallowed for external sites and discouraged between mutually hosted sites.
